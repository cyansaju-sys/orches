InstalarInstall

Tutti es una aplicación de escritorio para Linux y Windows (macOS llegará más adelante). No necesita permisos de administrador.

Linux

curl -fsSL https://github.com/cyansaju-sys/tutti/releases/latest/download/install.sh | bash

Descarga el AppImage de la última release en ~/.local/share/tutti/, crea el comando tutti en ~/.local/bin y la entrada del menú de aplicaciones. Si falta libfuse2 (en Arch, fuse2) funciona igual, solo que abre más despacio.

ComandoQué hace
install.shInstala o reinstala la última versión
install.sh --version 1.0.8Instala una versión concreta
install.sh --uninstallLo quita (tus ajustes en ~/.config/tutti se conservan)

Variables: TUTTI_HOME (dónde se guarda el AppImage) y TUTTI_REPO (usuario/repositorio).

Windows

Descarga Tutti-Setup-X.Y.Z.exe de la última release y ábrelo. Se instala para tu usuario y crea el acceso directo.

El instalador no está firmado: Windows puede mostrar el aviso de SmartScreen. Pulsa Más información → Ejecutar de todas formas.

Actualizaciones

La app se actualiza sola. Cuando sale una release nueva aparece el botón Actualizar a vX.Y.Z arriba a la derecha: al pulsarlo descarga la versión, verifica su hash y se reinicia para aplicarla. La primera vez que la abres después de actualizar, un diálogo te cuenta las novedades (o las de todas las versiones que te saltaste); puedes volver a verlas pulsando el número de versión junto al nombre de la app.

Tutti is a desktop app for Linux and Windows (macOS is coming later). It does not need administrator rights.

Linux

curl -fsSL https://github.com/cyansaju-sys/tutti/releases/latest/download/install.sh | bash

It downloads the AppImage of the latest release to ~/.local/share/tutti/, creates the tutti command in ~/.local/bin and the application menu entry. If libfuse2 is missing (on Arch, fuse2) it still works, it just opens more slowly.

CommandWhat it does
install.shInstalls or reinstalls the latest version
install.sh --version 1.0.8Installs a specific version
install.sh --uninstallRemoves it (your settings in ~/.config/tutti are kept)

Variables: TUTTI_HOME (where the AppImage is stored) and TUTTI_REPO (user/repository).

Windows

Download Tutti-Setup-X.Y.Z.exe from the latest release and open it. It installs for your user and creates the shortcut.

The installer is not signed: Windows may show the SmartScreen warning. Click More info → Run anyway.

Updates

The app updates itself. When a new release comes out, the Update to vX.Y.Z button appears at the top right: clicking it downloads the version, verifies its hash and restarts to apply it. The first time you open the app after updating, a dialog tells you what is new (or what changed in every version you skipped); you can see it again by clicking the version number next to the app name.

Primeros pasosFirst steps

  1. Abre un proyecto. Si no hay ninguno, el árbol de archivos te lo pide; también puedes elegir uno de los proyectos recientes de la pantalla de inicio o usar el botón Abrir otro proyecto de la cabecera del árbol.
  2. Abre un agente con Ctrl+Shift+N. Aparecen los que Tutti encontró instalados; escribe para filtrar y pulsa Enter.
  3. Trabaja como siempre. Cada agente es su propia terminal dentro de la ventana. Puedes abrir varios, y también editar archivos, mirar git o añadir servidores MCP mientras trabajan.

Sin agentes abiertos, el espacio central es la pantalla de inicio: el botón Elegir agente, los atajos básicos y tus proyectos recientes (con Abrir otro y una ✕ para quitar uno del historial). Si abres un archivo sin agentes, el editor ocupa todo el espacio. F1 muestra la lista completa de atajos.

Archivos y editorFiles and editor

El árbol usa los íconos de Material Icon Theme y muestra la letra de git en lo que cambió (M modificado, A/U nuevo, D borrado). Los archivos se abren en pestañas, ya editables, con colores, marcas de git en el margen (verde añadido, azul modificado, rojo borrado), autocompletado y recarga automática si otra herramienta cambia el archivo y aquí no hay cambios sin guardar.

Editar

  • Ctrl+S guarda; Ctrl+W cierra la pestaña (pregunta si hay cambios sin guardar).
  • El permiso Edición de la barra de título (o Ctrl+Shift+L) deja los archivos en solo lectura. Los archivos de más de 1 MB o que no son UTF-8 siempre se abren como solo lectura.
  • Autocompletado con Ctrl+Espacio; Enter o Tab aceptan y Esc cierra la sugerencia.
  • Resaltado de sintaxis para JavaScript/TypeScript (y JSX), Python, SQL, JSON, CSS, HTML, Markdown, XML, Vue y más.

El árbol

La cabecera tiene los botones Nuevo archivo, Nueva carpeta, Actualizar, Contraer todo y Abrir otro proyecto. También puedes pulsar en un espacio vacío para crear algo en la raíz. El nombre se escribe en el propio árbol: Enter crea y Esc cancela. Con el árbol enfocado se navega con las flechas (→ abre, ← cierra o sube, Enter abre) y la fila marcada sigue al ratón.

Cada proyecto recuerda lo suyo

Al cambiar de proyecto se cierran sus agentes, terminales y archivos (si hay cambios sin guardar, antes pregunta). Al volver a uno ya conocido se recupera la pestaña de la barra lateral y los archivos que tenías abiertos.

The tree uses Material Icon Theme icons and shows the git letter next to what changed (M modified, A/U new, D deleted). Files open in tabs, already editable, with colors, git marks in the gutter (green added, blue modified, red deleted), autocomplete and automatic reload if another tool changes the file and there are no unsaved changes here.

Editing

  • Ctrl+S saves; Ctrl+W closes the tab (it asks if there are unsaved changes).
  • The Editing permission in the title bar (or Ctrl+Shift+L) makes files read-only. Files larger than 1 MB or not in UTF-8 always open read-only.
  • Autocomplete with Ctrl+Space; Enter or Tab accept and Esc closes the suggestion.
  • Syntax highlighting for JavaScript/TypeScript (and JSX), Python, SQL, JSON, CSS, HTML, Markdown, XML, Vue and more.

The tree

The header has the buttons New file, New folder, Refresh, Collapse all and Open another project. You can also click an empty space to create something at the root. The name is typed in the tree itself: Enter creates and Esc cancels. With the tree focused you can navigate with the arrows (→ opens, ← closes or goes up, Enter opens) and the marked row follows the mouse.

Buscar y reemplazarFind and replace

En el archivo abierto

Ctrl+F abre un cuadro flotante arriba a la derecha del editor con distinguir mayúsculas (Aa), palabra completa (ab) y expresión regular (.*), el contador («3 de 12») y los botones anterior / siguiente. Ctrl+H añade la fila de reemplazo (Reemplazar y Todo). Enter / Shift+Enter recorren las coincidencias y Esc cierra.

En todo el proyecto

El apartado Buscar de la barra lateral (Ctrl+Shift+F) agrupa los resultados por archivo; al pulsar uno se abre en esa línea con la coincidencia seleccionada.

  • Filtros acepta globs separados por comas para incluir y excluir: *.ts, src/** · *.test.ts, docs/.
  • Respeta el .gitignore si el proyecto usa git, y salta binarios y archivos de más de 1 MB.
  • Se corta a las 5000 coincidencias o 500 archivos (el contador muestra «+»).

Reemplazar en el proyecto

Ctrl+Shift+H (o la flecha a la izquierda del campo) despliega el campo de reemplazo. Se puede reemplazar por archivo o todo a la vez, siempre pidiendo confirmación. Con expresión regular admite $1, $& y $$; conserva los fines de línea y salta los archivos abiertos con cambios sin guardar para no pisarlos.

In the open file

Ctrl+F opens a floating box at the top right of the editor with match case (Aa), whole word (ab) and regular expression (.*), the counter (“3 of 12”) and the previous / next buttons. Ctrl+H adds the replace row (Replace and All). Enter / Shift+Enter go through the matches and Esc closes it.

Across the project

The Search section of the sidebar (Ctrl+Shift+F) groups results by file; clicking one opens it at that line with the match selected.

  • Filters accepts comma-separated globs to include and exclude: *.ts, src/** · *.test.ts, docs/.
  • It respects .gitignore if the project uses git, and skips binaries and files larger than 1 MB.
  • It stops at 5000 matches or 500 files (the counter shows “+”).

Replace across the project

Ctrl+Shift+H (or the arrow to the left of the field) shows the replace field. You can replace per file or all at once, always asking for confirmation. With a regular expression it supports $1, $& and $$; it keeps line endings and skips open files with unsaved changes so it never overwrites them.

Agentes y terminalesAgents and terminals

Ctrl+Shift+N abre un agente de los instalados. Tutti los busca en el PATH, en el de tu shell de login y en las carpetas habituales, así que funciona aunque lances la app desde el menú. Ctrl+Shift+T abre una shell en el proyecto como sección aparte, con varias terminales en una lista a la derecha.

Añadir el tuyo

En ¿No aparece el tuyo? Añadir otro agente… escribes un nombre y el comando (con argumentos si hace falta), o eliges uno de los ejecutables que la app encuentra en tus carpetas bin. Los propios sin logo llevan una insignia generada con su inicial. Se quitan desde la lista de agentes.

Terminales

  • Varias terminales a la vez, en una lista a la derecha del panel; el panel se puede maximizar y cerrar entero.
  • Si un proceso no arranca o termina, un aviso lo explica (comando no encontrado, señal, código de salida).
  • Con varios agentes, se reparten en cuadrícula y Ctrl+AvPág / RePág salta de uno a otro.

Varias ventanas

El botón de la barra de título (o Nueva ventana vacía en el menú del lanzador, con clic derecho sobre el icono en Linux) abre otra ventana sin proyecto. Es otro proceso, con sus propios agentes, su servidor de tareas y su proyecto. Los ajustes se comparten, así que lo último que abras en cualquier ventana es lo que se reabre al iniciar. La ventana nueva se abre en el monitor donde está el cursor.

Ctrl+Shift+N opens an installed agent. Tutti looks for them in the PATH, in your login shell's one and in the usual folders, so it works even if you launch the app from the menu. Ctrl+Shift+T opens a shell in the project as a separate section, with several terminals in a list on the right.

Agents it detects

Claude Code, OpenCode, Codex, Gemini CLI, Aider, Cursor, Goose, Amp, Qwen Code, Copilot CLI, Droid, Kimi, Crush, Kilo, Cline, Plandex, Auggie, Forge, Mistral Vibe and Warp, each with its logo. Antigravity (agy) is added by hand.

Add your own

In Not listed? Add another agent… you type a name and the command (with arguments if needed), or pick one of the executables the app finds in your bin folders. Custom ones without a logo get a badge generated from their initial. They are removed from the agents list.

Terminals

  • Several terminals at once, in a list on the right of the panel; the panel can be maximized and closed as a whole.
  • If a process does not start or ends, a notice explains it (command not found, signal, exit code).
  • With several agents, they are laid out in a grid and Ctrl+Page Down / Page Up jumps between them.

Several windows

The title bar button (or New empty window in the launcher menu, right-clicking the icon on Linux) opens another window with no project. It is another process, with its own agents, its own task server and its own project. Settings are shared, so the last thing you open in any window is what reopens at startup. The new window opens on the monitor where the cursor is.

Reparto de tareasTask delegation

Tutti abre un servidor MCP local (solo en 127.0.0.1, con un token distinto en cada ejecución) y conecta a cada agente a él con cuatro herramientas:

HerramientaPara qué sirve
list_agentsVer los agentes abiertos y los instalados, con su modelo, nivel y límite de uso
delegate_taskMandar una tarea a un agente abierto o pedir uno nuevo (incluso del mismo tipo)
wait_agentEsperar a que un agente termine y recibir las últimas líneas de su pantalla
read_agent_outputLeer la pantalla de un agente y saber si sigue ocupado

El primer agente que abres es el líder. Los que él (u otro) abre salen en su propio panel marcado «sub de …», y el apartado Agentes de la barra lateral lista las tareas delegadas con su estado (trabajando, terminada, cerrada), modelo, dificultad y duración. Cuando un agente termina, Tutti avisa al que se la mandó.

Asigna según la capacidad

Si el agente pasa difficulty (easy, medium, hard), Tutti revisa la lista, comprueba el nivel del modelo (basic, standard, advanced) y su límite de uso, y elige el más adecuado: el justo para la tarea (no gasta uno avanzado en algo fácil), libre antes que ocupado y que no tenga el límite agotado. Con agent: "auto" elige él; si el pedido no tiene capacidad suficiente se rechaza y se propone otro (force lo mantiene). También se puede pedir un model concreto para los agentes que lo permiten al abrirse.

Tutti opens a local MCP server (only on 127.0.0.1, with a different token on every run) and connects every agent to it with four tools:

ToolWhat it is for
list_agentsSee the open and installed agents, with their model, level and usage limit
delegate_taskHand a task to an open agent or ask for a new one (even of the same type)
wait_agentWait for an agent to finish and get the last lines of its screen
read_agent_outputRead an agent's screen and know whether it is still busy

The first agent you open is the leader. The ones it (or another) opens appear in their own panel tagged “sub of …”, and the Agents section of the sidebar lists delegated tasks with their status (working, done, closed), model, difficulty and duration. When an agent finishes, Tutti notifies the one that sent the task.

Assigns by capability

If the agent passes difficulty (easy, medium, hard), Tutti reviews the list, checks the model level (basic, standard, advanced) and its usage limit, and picks the most suitable: just enough for the task (it does not spend an advanced one on something easy), idle before busy, and not out of limit. With agent: "auto" it chooses; if the requested one lacks enough capability it is rejected and another is suggested (force keeps it). A specific model can also be requested for agents that allow it on launch.

Contexto del proyectoProject context

El apartado Contexto (Ctrl+Shift+K) guarda un texto sobre el proyecto —qué es, cómo se ejecuta, convenciones— que leen los agentes que abras en él: Claude Code lo recibe como parte de su prompt de sistema y OpenCode como archivo de instrucciones. Funciona también si el agente se abre en una subcarpeta y sin el reparto de tareas.

  • Vive fuera del repositorio, en <config>/tutti/<proyecto>-<huella>/contexto.md, y se guarda solo (o con Guardar).
  • La plantilla inicial sin tocar no se envía a los agentes.
  • Generar con IA lo redacta un agente a partir de un resumen pequeño del proyecto (estructura, package.json, inicio del README, últimos commits), sin dejarle explorar, para gastar muy pocos tokens. Con Claude usa el modelo pequeño haiku; si ningún agente responde arma un borrador con reglas. Se escribe en el idioma de la interfaz y se cancela al cambiar de apartado.

The Context section (Ctrl+Shift+K) stores a text about the project —what it is, how to run it, conventions— that the agents you open in it read: Claude Code receives it as part of its system prompt and OpenCode as an instructions file. It works even if the agent opens in a subfolder and without task delegation.

  • It lives outside the repository, at <config>/tutti/<project>-<hash>/contexto.md, and saves itself (or with Save).
  • The untouched starting template is not sent to the agents.
  • Generate with AI has an agent write it from a small summary of the project (structure, package.json, start of the README, latest commits), without letting it explore, to spend very few tokens. With Claude it uses the small haiku model; if no agent answers it builds a draft with rules. It is written in the interface language and cancelled when you leave the section.

Servidores MCP y tiendaMCP servers and store

Lee, añade y quita los servidores de Claude Code, OpenCode, Gemini CLI, Codex y Antigravity (globales, del proyecto y .mcp.json) usando la CLI de cada agente para respetar su formato.

  • Un servidor, una tarjeta. Al abrirla ves en qué agentes está aplicado (Aplicado en), su comando o URL, cabeceras y variables (los secretos ocultos hasta que lo pides) y dónde se guarda. Puedes copiarlo a otro agente o quitarlo de uno solo.
  • La papelera de la tarjeta lo quita de todos los agentes, pidiendo confirmación.
  • + abre Añadir servidor MCP: remoto (URL y cabeceras) o local (comando, argumentos y variables), los agentes de destino y el alcance (todos los proyectos o solo este). Codex y Antigravity solo guardan servidores globales.
  • La tarjeta tutti es el servidor de la propia app (el reparto de tareas) y muestra a qué agentes llega.
  • Las secciones Tutti, Instalados, Recomendados y Disponibles se pliegan y recuerdan su estado.

Tienda

El buscador de arriba consulta el registro oficial de MCP (registry.modelcontextprotocol.io) con el aspecto de las extensiones de VS Code: icono, nombre, descripción, quién lo publica, si es local o remoto y el botón Instalar. Los más conocidos (Context7, Playwright, GitHub, Chrome DevTools, Notion, Figma, Linear, Atlassian, Sentry, Supabase, Stripe, Cloudflare, Vercel, Serena) salen primero en Recomendados; al buscar, lo que mejor coincide va arriba.

  1. Al pulsar un servidor se abre su ficha: qué es, quién lo publica, versión, repositorio, el comando exacto que se ejecutará y las variables que pide.
  2. Continuar abre Añadir servidor MCP ya relleno; completas lo que falte y eliges los agentes.

Solo se ofrece lo que Tutti sabe instalar: paquetes npm (con npx), pypi (con uvx) y servidores remotos por URL (streamable-http o sse). Necesitas node o uv instalados para los locales.

Instalar un servidor MCP ejecuta código de terceros en tu equipo y el registro no lo revisa. Comprueba el comando y de dónde viene antes de continuar. Sin conexión, la tienda muestra un aviso con Reintentar; lo ya instalado sigue funcionando.

It reads, adds and removes the servers of Claude Code, OpenCode, Gemini CLI, Codex and Antigravity (global, project and .mcp.json) using each agent's CLI to respect its format.

  • One server, one card. Opening it shows which agents it is applied to (Applied to), its command or URL, headers and variables (secrets hidden until you ask) and where it is stored. You can copy it to another agent or remove it from just one.
  • The card's trash can removes it from every agent, asking for confirmation.
  • + opens Add MCP server: remote (URL and headers) or local (command, arguments and variables), the target agents and the scope (all projects or just this one). Codex and Antigravity only store global servers.
  • The tutti card is the app's own server (task delegation) and shows which agents it reaches.
  • The Tutti, Installed, Recommended and Available sections fold and remember their state.

Store

The search box at the top queries the official MCP registry (registry.modelcontextprotocol.io) styled like VS Code extensions: icon, name, description, who publishes it, whether it is local or remote and the Install button. The best-known ones (Context7, Playwright, GitHub, Chrome DevTools, Notion, Figma, Linear, Atlassian, Sentry, Supabase, Stripe, Cloudflare, Vercel, Serena) come first under Recommended; when searching, the best match goes on top.

  1. Clicking a server opens its page: what it is, who publishes it, version, repository, the exact command that will run and the variables it asks for.
  2. Continue opens Add MCP server already filled in; you complete what is missing and pick the agents.

Only what Tutti knows how to install is offered: npm packages (with npx), pypi (with uvx) and remote servers by URL (streamable-http or sse). You need node or uv installed for the local ones.

Installing an MCP server runs third-party code on your computer and the registry does not review it. Check the command and where it comes from before continuing. Offline, the store shows a notice with Retry; what is already installed keeps working.

Consumo e historialUsage and history

El apartado Consumo (Ctrl+Shift+U) muestra, por agente instalado:

  • Los tokens de la ventana de 5 h de Claude, de hoy, de 7 días y totales.
  • Los porcentajes reales de límite que da Anthropic (sesión de 5 h, semanal, por modelo) y cuándo se reinician. Se consultan una vez al abrir la pestaña, con la sesión de Claude Code; si caducó, basta abrir Claude Code una vez.
  • El consumo de OpenCode, y de Antigravity el historial de conversaciones (no guarda tokens en local).

Historial del proyecto

GitGit

Cambios y commit

  • Cambios con preparar / quitar, y secciones preparados y cambios que se pliegan. Al pulsar un archivo se abre su comparación.
  • Mensaje de commit con IA. La ✨ del campo le pide a un agente instalado un mensaje en Conventional Commits a partir de lo que tienes preparado, y lo deja para que lo revises. Se ve qué agente lo redacta. Si ninguno responde, se arma con reglas sencillas sobre los archivos tocados.
  • Un solo botón, un paso por pulsación. Con mensaje hace Commit; después pasa a Push o, si faltan cambios del remoto, a Pull (solo avance simple, nunca une a ciegas), con una animación del progreso. Sin repositorio remoto solo ofrece commit. Funciona también en un repositorio recién creado, sin commits.

Ramas

Ctrl+Shift+G abre Git; el chip con el nombre de la rama, en la barra de título, abre el selector: un panel al estilo de VS Code con la fecha y el último commit de cada rama, búsqueda, cambio de rama (local o remota), crear una nueva (desde la actual o a partir de… otra) y desproteger para ir a una rama o commit sin crear rama.

Comparar cambios

Una pestaña con la comparación en dos columnas (lo anterior a la izquierda, lo nuevo a la derecha), con las líneas añadidas y borradas resaltadas y los tramos largos sin cambios plegados.

Commits

El chip Commits abre el grafo de todas las ramas, con las etiquetas de rama, remota y tag, los merges atenuados y una fila de cambios sin commit que lleva a la sección Git.

  • Clic en un commit: debajo salen sus datos y los archivos que cambió con +N −N; en un merge, lo que trajo la rama unida. Al pulsar un archivo se abre su comparación.
  • Clic derecho: etiqueta, crear rama aquí, cambiar de rama, cherry-pick, revertir, unir (con no-ff, squash y no commit), rebase, reset (suave, mixto o duro) y copiar hash o mensaje. Las operaciones que cambian el historial piden confirmación, y si dan conflictos se cancelan sin dejar el repositorio a medias.

Changes and commit

  • Changes with stage / unstage, and staged and changes sections that fold. Clicking a file opens its comparison.
  • AI commit message. The ✨ in the field asks an installed agent for a Conventional Commits message based on what you have staged, and leaves it for you to review. You can see which agent writes it. If none answers, it is built with simple rules over the touched files.
  • One button, one step per press. With a message it does Commit; afterwards it becomes Push or, if the remote has new changes, Pull (fast-forward only, it never merges blindly), with a progress animation. Without a remote it only offers commit. It also works in a freshly created repository with no commits.

Branches

Ctrl+Shift+G opens Git; the chip with the branch name in the title bar opens the picker: a VS Code-style panel with the date and last commit of each branch, search, switching branch (local or remote), creating a new one (from the current or from… another) and checkout detached to go to a branch or commit without creating a branch.

Comparing changes

A tab with the two-column comparison (before on the left, after on the right), with added and deleted lines highlighted and long unchanged stretches folded.

Commits

The Commits chip opens the graph of every branch, with branch, remote and tag labels, dimmed merges and an uncommitted changes row that leads to the Git section.

  • Click a commit: below you get its data and the files it changed with +N −N; for a merge, what the merged branch brought. Clicking a file opens its comparison.
  • Right click: tag, create branch here, switch branch, cherry-pick, revert, merge (with no-ff, squash and no commit), rebase, reset (soft, mixed or hard) and copy hash or message. Operations that change history ask for confirmation, and if they hit conflicts they are cancelled without leaving the repository half done.

Apariencia e idiomaAppearance and language

The gear at the bottom of the sidebar opens the settings, with two submenus that open on hover (they show the current value):

Privacidad y seguridadPrivacy and security

  • La app solo sale a internet para consultar tus límites en Anthropic (con la sesión de Claude Code; el token nunca se guarda ni se muestra), buscar actualizaciones en GitHub y, si abres la tienda, consultar el registro de MCP.
  • El servidor de reparto de tareas escucha únicamente en 127.0.0.1 y exige un token distinto en cada ejecución.
  • No hay cuentas, analítica ni telemetría.
  • Borrar un archivo lo manda a la papelera. Las operaciones de git que cambian el historial piden confirmación.
  • Los secretos de los servidores MCP se ocultan en pantalla hasta que pides verlos.
  • The app only goes online to query your limits at Anthropic (with the Claude Code session; the token is never stored or shown), check for updates on GitHub and, if you open the store, query the MCP registry.
  • The task delegation server listens only on 127.0.0.1 and requires a different token on every run.
  • There are no accounts, analytics or telemetry.
  • Deleting a file sends it to the trash. Git operations that change history ask for confirmation.
  • MCP server secrets are hidden on screen until you ask to see them.

Solución de problemasTroubleshooting

No aparece mi agente en la lista
Tutti busca el ejecutable en el PATH, en el de tu shell de login y en las carpetas habituales. Si está en otro sitio, usa Añadir otro agente… y elige el ejecutable o escribe la ruta completa.
El AppImage tarda en abrir
Falta libfuse2 (en Arch, fuse2). Funciona igual, solo que más despacio.
Windows muestra SmartScreen
El instalador no está firmado. Pulsa Más información → Ejecutar de todas formas.
Un agente no ve las herramientas de Tutti
Ábrelo desde Tutti (fuera de la app no recibe la configuración de su sesión). Revisa la tarjeta tutti de la pestaña MCP: si un agente sale en rojo, el mensaje dice por qué. Comprueba que "orchestration" no esté en false.
En Antigravity la tarjeta dice «No existe …»
El registro apunta a una ruta vieja (por ejemplo tras mover la app de carpeta). Se repara solo al abrir Tutti con Antigravity instalado; ábrelo de nuevo.
La tienda no carga
Necesita conexión al registro oficial de MCP. Pulsa Reintentar. Lo que ya tenías instalado sigue funcionando sin red.
Un servidor de la tienda no arranca
Los locales necesitan node (npx) o uv (uvx) instalados y las variables que pida la ficha rellenas.
La ventana no se abre donde esperaba (Wayland)
En Wayland es el compositor quien decide la posición; Tutti no puede forzarla. En KDE se abre en el monitor del cursor.
Quitar Tutti del todo
install.sh --uninstall; tus ajustes siguen en ~/.config/tutti (bórralos si quieres empezar de cero).
My agent is not in the list
Tutti looks for the executable in the PATH, in your login shell's one and in the usual folders. If it is somewhere else, use Add another agent… and pick the executable or type the full path.
The AppImage is slow to open
libfuse2 is missing (on Arch, fuse2). It works anyway, just more slowly.
Windows shows SmartScreen
The installer is not signed. Click More info → Run anyway.
An agent does not see Tutti's tools
Open it from Tutti (outside the app it does not get its session's configuration). Check the tutti card in the MCP tab: if an agent shows in red, the message says why. Make sure "orchestration" is not false.
In Antigravity the card says “… does not exist”
The registration points to an old path (for example after moving the app's folder). It repairs itself when Tutti opens with Antigravity installed; open it again.
The store does not load
It needs a connection to the official MCP registry. Click Retry. What you already had installed keeps working offline.
A server from the store does not start
Local ones need node (npx) or uv (uvx) installed and the variables the page asks for filled in.
The window does not open where I expected (Wayland)
On Wayland the compositor decides the position; Tutti cannot force it. On KDE it opens on the cursor's monitor.
Removing Tutti completely
install.sh --uninstall; your settings stay in ~/.config/tutti (delete them to start from scratch).

Publicar una release

  1. Sube version en package.json y añade su sección ## x.y.z a CHANGELOG.md y a CHANGELOG.en.md; haz commit.
  2. git tag vX.Y.Z && git push origin master vX.Y.Z.

GitHub Actions comprueba que el tag coincide con la versión y que los dos changelogs la mencionan, pasa tipos y pruebas, empaqueta el AppImage y el instalador de Windows y crea la release (Tutti-X.Y.Z-x86_64.AppImage, latest-linux.yml, install.sh, Tutti-Setup-X.Y.Z.exe y latest.yml, que es lo que lee el actualizador). Si el build de Windows falla, la de Linux sale igual.
